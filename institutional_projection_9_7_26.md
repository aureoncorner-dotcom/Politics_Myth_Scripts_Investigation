## v0.2 test

For a declared domain `D`, documented update or sampling rule `U`, and observation `B`, a label is an autonomous predictive state only if

```text
B(x) = B(y)  implies  B(Ux) = B(Uy)
```

for every comparison the stated claim requires.

For probabilistic outcomes, one observed mismatch is not enough to prove unequal laws. The test must instead compare the next-outcome distributions using a declared statistical rule.

### Anti-hindsight rule

The complete future-output sequence may define the finest equivalence needed for a formal predictive state. It may **not** be supplied to a real-world predictor as if it were known at the original classification time.

Accordingly, a claim that Revelation operates as a prewritten predictive script requires:

1. a frozen functional codebook;
2. a dated assignment made before the outcome window;
3. a fixed sampling address defining what counts as the “next” event or function;
4. comparable people, offices, systems, or historical episodes assigned under the same rule;
5. retained failures and competing assignments;
6. a declared success tolerance and coverage requirement.

Without those elements, the material can support retrospective literary or institutional comparison, but not a predictive-script finding.

## Case findings

### `PD-01` — Fuel shock and Spirit

The ordinary evidence lane already supports a contributory sequence while retaining Spirit's prior bankruptcy, liquidity, financing, and business conditions.

The predictive question is narrower:

```text
Does “severe jet-fuel shock” uniquely determine the next carrier-level operating state?
```

The supplied case record does not include all similarly exposed carriers, comparable shock windows, hedge positions, liquidity states, rescue options, and decisions. The prediction is therefore unresolved, not closed. Spirit remains an observed case of a material precipitating shock acting on a vulnerable firm, not proof of a universal fuel-shock law.

The proposed interaction `fuel shock × firm fragility` is substantively plausible and consistent with the baseline narrative. It is not a measured cross-difference in this record and is therefore retained as an interaction candidate only.

### `PD-02` — Custody, ingestion, and use

The current record can observe custody without observing the successor chain.

```text
receipt
→ custody state
→ ingestion/build
→ query
→ output or target record
→ decision reliance
→ person-level consequence
```

One arrow cannot inherit proof from the previous arrow. The sampling address for each step is the corresponding dated log, audit entry, order, or decision receipt. Until those records are available, custody does not form an autonomous predictor of operational use.

This is a sequential conjunction, not automatically a statistical interaction. Calling it an interaction would blur two different questions: whether every transition occurred and whether two variables have a non-additive effect.

### `PD-03` — Chronology control

The named 2021 proceeds cannot produce confirmation expenditures that had already occurred. The proposed update lies outside the causal time domain. Predictive geometry adds no useful result beyond the ordinary date test and should be omitted from public-facing prose for this claim.

This remains the method's anti-bloat control.

### `PD-04` — Directive title and legal successor

Define the coarse present observation as:

```text
B(x) = presidential directive
```

and the successor witness as:

```text
B(Ux) = operative authority for the challenged action after legal review
```

The *Youngstown* seizure order and the proclamation reviewed in *Trump v. Hawaii* share the coarse present label but differ in statutory context and legal disposition. This is a located same-label/different-successor pair.

Therefore:

```text
presidential-directive title alone
≠ autonomous predictive state for operative authority
```

The smallest useful repair must retain, at minimum, the asserted Article II domain, statutory provision and delegation breadth, required findings, conflict with enacted law, appropriations, implementation act, and procedural posture.

### `PD-05` — Revelation grammar versus predictive script

The functional map remains valid as a comparative reading device. Its stronger use as a prewritten predictive script would require the function label to constrain later behavior without being rewritten after later events are known.

The current material does not contain a prospectively frozen, adequately covered candidate set. It therefore cannot run the predictive closure test. The correct status is `NOT_EVALUATED`, not passed.

A future admissible test would create records of this form:

| Required field | Example form |
|---|---|
| Assignment time | Timestamp preceding the outcome window |
| Unit | Person, office, firm, coalition, platform, or state—never silently exchanged |
| Frozen role vector | Required textual functions present/absent/unknown |
| Sampling window | Fixed next event, fixed interval, or fixed institutional decision |
| Predicted successor | Specific function rather than a flexible narrative resemblance |
| Falsifier | Successor behavior that contradicts the assigned role |
| Comparator class | All eligible candidates, including nonmatches and failures |
| Outcome status | Supported, failed, unresolved, or inapplicable under the frozen rule |

If the role is assigned or revised using the outcome it is later said to predict, the result is circular and inadmissible as a prediction. It may still be discussed as retrospective symbolism.

## Material-pressure carry-forward

The resource/capacity source improves the separate material-pressure instrument, but it does not supply a new factual result. Its appropriate translation is a typed ledger:

```text
resource available
− task/essential use
− debt/tax/coordination cost
− maintenance requirement
− regeneration investment
= remaining margin for that resource and interval
```

Money, time, energy, housing access, health, and institutional capacity remain separate accounts. The same aggregate output can coexist with different household margins or different maintenance conditions. This reinforces the existing finding that debt stock, APR, payment burden, wages, prices, openings, hires, and legal posture cannot be collapsed into one economy score.

It also adds a useful allocation record:

```text
named resource → allocation decision → recipient/beneficiary
              → affected capacity → correction/exit route → time horizon
```

This is bookkeeping for evidence acquisition, not thermodynamic measurement and not proof of coordinated intent.

## Contamination controls

| Risk | v0.2 control |
|---|---|
| Later outcome used to define the predictor | Reject as hindsight leakage |
| Flexible meaning of “next” | Freeze the sampling address before comparison |
| Similarity treated as same-fiber equivalence | Require a declared partition or coding rule |
| No counterexample found in a partial record | `UNRESOLVED` or `SAMPLE_CONSISTENT`, never universal closure |
| One random outcome treated as an unequal probability law | Require repeated trials, exact legal/logical rule, or justified statistical comparison |
| Compound narrative treated as an interaction effect | Require the matched cross-difference or an equivalent design |
| Mathematical topology imported into institutions | Prohibited without a defined space, topology, data coverage, and empirical interpretation |
| Symbolic role treated as person identity | Prohibited; retain person, office, network, system, and literary function as separate types |
| Geometry used where chronology decides the case | Omit the geometry, as in `PD-03` |
